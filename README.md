# 格口交接账

面向驿站运营稽核员。排序后按签入、开门、关门、取件状态机核销，忽略同事件重传并隔离非法跳转。复算后按保管单核对独立清单，查看单据证据和差值，再登记复核结论。

## 启动

```sh
docker compose up --build
```

默认访问 http://localhost:18286。
打开工作台，点击运行即可使用内置的班次样例。选择导入可以换成自己的来源与独立账 CSV。
口径默认自动识别：没有现场来源与事件原因两列的旧班次按 1.0 重算；带两列的新班次按 2.0 复算，缺证据的行隔离且不计入正式差异。
样例在 `sample_data/`，`shift.csv` 有分页表头、冲突修订、坏行、空值哨兵与业务拒绝，`external.csv` 有单边与数值差异；
`shift_v2.csv` / `external_v2.csv` 演示新口径下证据缺失的隔离。端口可通过 `APP_PORT` 覆盖。运行记录和复核历史保存在 `ledger` 卷。

## 操作

- 在门磁回放展开业务证据，核对原始字段与计算项。
- 在隔离裁决逐行检查原因。独立对账按键对比外部账并列出差值。
- 在批次复算重跑当前输入。在交付复核提交带版本意见，并导出证据包。
- 工作台顶部显示本批采用的口径；被隔离的记录列在 `caliber.isolated`，导出证据包同样携带。
- 口径切换失败时不写入新批次，并保留、打开旧版正式结论。
